# OOP22_Init
# Назва проекту
StudyTest
## Про що проект
ПЗ для тестування знань студентів: викладач створює тести,
студенти проходять їх і отримують оцінку.

## Навіщо цей проект
Навчитися програмувати мовою Java, застосовувати ООП та UML.

## Основні сутності
- Студент
- Викладач
- Тест
- Питання
- Результат
